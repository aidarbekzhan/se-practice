# Smart Campus Room Availability Checker (SIS #04)

Smart Campus Room Availability Checker web application with catalog search, capacity & equipment filtering, and automated availability checking.

## Setup

Install project dependencies:

```bash
npm install
```

## Running the Application

Start the local Vite development server:

```bash
npm run dev
```

Open the displayed localhost URL in your browser to interact with the application.

## Running Tests

Execute the automated Vitest test suite:

```bash
npx vitest run
```
